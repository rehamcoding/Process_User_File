# Process_User_File
A Python project for processing user JSON files, validating data, handling errors, and logging operations.

## Features
- Process user JSON files.
- Validate user information.
- Handle file-related and data-related errors.
- log successful operations and errors.

## Technologies

- Python
- pathlib
- json
- logging


## Project Structure

```text
Process_User_File/
├── main.py
├── file_manager.py
├── users/
├── app.log
└── README.md
```

## How to Run

1. Clone the repository.

2. Open the project directory.

3. Run the application:

```python main.py```

## Purpose

This project was built to practice Python file handling, data validation, exception handling, and logging.
